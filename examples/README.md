# Examples

This directory contains examples for training and running machine learning models with **Flux**.

To run the example scripts:
1. Install Flux in a virtual environment.
2. Install the requirements specific to the example by navigating to the example folder and running:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Examples on Remote Hardware

You can adapt `run_on_remote.py` to run these examples on remote hardware.
